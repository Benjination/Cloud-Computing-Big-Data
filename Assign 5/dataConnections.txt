========================================
EARTHQUAKE DATA CONNECTIONS FOR VISUALIZATION
========================================

This document outlines meaningful data relationships from the earthquake dataset
that will create impactful, understandable visualizations for general audiences.

FIELDS EXCLUDED (Too Technical for Casual Enthusiasts):
- nst, gap, dmin, rms (seismic network metrics)
- horizontalError, depthError, magError, magNst (measurement errors)
- net, id, updated, status, locationSource, magSource (administrative data)

FIELDS INCLUDED (High Public Interest):
- time: When the earthquake occurred
- latitude, longitude: Geographic location
- depth: How deep underground (km)
- mag: Magnitude (strength/size)
- magType: Type of magnitude measurement
- place: Human-readable location
- type: Event classification


========================================
1. PIE CHART DATA CONNECTION
========================================

CHART TITLE: "Where Do Earthquakes Happen? Regional Distribution"

DATA MAPPING:
- Extract STATE/REGION from the "place" field
  Examples: "California", "Alaska", "Texas", "Hawaii", "Puerto Rico", "International"
  
- Group by: Geographic Region
- Value: Count of earthquakes per region
- Purpose: Shows which areas experience the most seismic activity

WHY IT'S IMPACTFUL:
- Immediately shows hotspots for earthquake activity
- Helps people understand if they live in an earthquake-prone area
- California and Alaska are expected to dominate
- Creates geographic awareness

EXAMPLE DATA STRUCTURE:
[
  { region: "California", count: 3245 },
  { region: "Alaska", count: 2891 },
  { region: "Texas", count: 1567 },
  { region: "Hawaii", count: 892 },
  { region: "Oklahoma", count: 445 },
  { region: "Other US States", count: 567 },
  { region: "International", count: 358 }
]

CODE IMPLEMENTATION:
```javascript
// Parse region from place field
function extractRegion(place) {
  if (!place) return "Unknown";
  if (place.includes("CA") || place.includes("California")) return "California";
  if (place.includes("Alaska")) return "Alaska";
  if (place.includes("Texas")) return "Texas";
  if (place.includes("Hawaii")) return "Hawaii";
  if (place.includes("Oklahoma")) return "Oklahoma";
  if (place.includes("Nevada")) return "Nevada";
  if (place.includes("Puerto Rico")) return "Puerto Rico";
  if (place.includes("Washington")) return "Washington";
  // Add more as needed
  return "Other/International";
}

// Count earthquakes by region
const regionCounts = d3.rollup(
  earthquakeData,
  v => v.length,
  d => extractRegion(d.place)
);
```


========================================
2. VERTICAL BAR CHART DATA CONNECTION
========================================

CHART TITLE: "Earthquake Intensity: How Strong Are They?"

DATA MAPPING:
- X-axis: Magnitude ranges (categories)
  • "Micro (0-2)" - Often not felt
  • "Minor (2-3)" - Felt, rarely causes damage
  • "Light (3-4)" - Noticeable shaking
  • "Moderate (4-5)" - Can cause damage
  • "Strong (5+)" - Serious damage possible
  
- Y-axis: Number of earthquakes
- Purpose: Shows the distribution of earthquake strengths

WHY IT'S IMPACTFUL:
- Shows that most earthquakes are small and harmless
- The visual "pyramid" effect (many small, few large) is educational
- Helps contextualize magnitude numbers (what does 2.5 really mean?)
- Answers: "How common are dangerous earthquakes?"

EXAMPLE DATA STRUCTURE:
[
  { range: "Micro (0-2)", label: "0-2", count: 5234 },
  { range: "Minor (2-3)", label: "2-3", count: 3456 },
  { range: "Light (3-4)", label: "3-4", count: 876 },
  { range: "Moderate (4-5)", label: "4-5", count: 234 },
  { range: "Strong (5+)", label: "5+", count: 165 }
]

CODE IMPLEMENTATION:
```javascript
// Categorize by magnitude with labels
function categorizeMagnitude(mag) {
  if (mag < 2) return { range: "Micro (0-2)", order: 1 };
  if (mag < 3) return { range: "Minor (2-3)", order: 2 };
  if (mag < 4) return { range: "Light (3-4)", order: 3 };
  if (mag < 5) return { range: "Moderate (4-5)", order: 4 };
  return { range: "Strong (5+)", order: 5 };
}

const magnitudeData = Array.from(
  d3.rollup(
    earthquakeData,
    v => v.length,
    d => categorizeMagnitude(d.mag).range
  ),
  ([range, count]) => ({ range, count })
).sort((a, b) => categorizeMagnitude(a.range).order - categorizeMagnitude(b.range).order);
```


========================================
3. HORIZONTAL BAR CHART DATA CONNECTION
========================================

CHART TITLE: "Depth Matters: How Deep Do Earthquakes Occur?"

DATA MAPPING:
- X-axis: Number of earthquakes
- Y-axis: Depth categories
  • "Shallow (0-10 km)" - Near surface, more destructive
  • "Intermediate (10-50 km)" - Mid-crust
  • "Deep (50-100 km)" - Lower crust
  • "Very Deep (100+ km)" - Upper mantle
  
- Purpose: Shows the vertical distribution of seismic activity

WHY IT'S IMPACTFUL:
- Shallow earthquakes are more dangerous (closer to surface)
- Shows where Earth's crust is most active
- Educational about Earth's structure
- Horizontal layout works well for categorical depth ranges

EXAMPLE DATA STRUCTURE:
[
  { depth: "Shallow (0-10 km)", count: 4567 },
  { depth: "Intermediate (10-50 km)", count: 3234 },
  { depth: "Deep (50-100 km)", count: 1456 },
  { depth: "Very Deep (100+ km)", count: 708 }
]

CODE IMPLEMENTATION:
```javascript
// Categorize by depth
function categorizeDepth(depth) {
  if (depth < 10) return "Shallow (0-10 km)";
  if (depth < 50) return "Intermediate (10-50 km)";
  if (depth < 100) return "Deep (50-100 km)";
  return "Very Deep (100+ km)";
}

const depthData = Array.from(
  d3.rollup(
    earthquakeData,
    v => v.length,
    d => categorizeDepth(d.depth)
  ),
  ([depth, count]) => ({ depth, count })
);
```


========================================
4. SCATTER PLOT (X,Y) DATA CONNECTION
========================================

CHART TITLE: "Earthquake Map: Location & Power"

DATA MAPPING:
- X-axis: Longitude (East-West position)
- Y-axis: Latitude (North-South position)
- Point size: Magnitude (bigger = stronger)
- Point color: Depth (gradient from shallow=red to deep=blue)
- Tooltip: Location name, magnitude, depth

PURPOSE: Geographic visualization of earthquake distribution

WHY IT'S IMPACTFUL:
- Creates a "live map" of earthquake activity
- Immediately shows geographic patterns (Ring of Fire, fault lines)
- Size variation shows power differences at a glance
- Color coding adds depth information without cluttering
- Most intuitive for general audiences - it's a map!

VISUAL INSIGHTS REVEALED:
- West coast concentration (Pacific Ring of Fire)
- Alaska's high activity
- Texas cluster (likely fracking-related)
- Sparse activity in central/eastern US
- Clustering along known fault lines

EXAMPLE DATA STRUCTURE:
[
  { 
    lat: 33.065, 
    lon: -116.461, 
    mag: 1.73, 
    depth: 12.05,
    place: "13 km E of Julian, CA",
    color: "shallow" // derived from depth
  },
  { 
    lat: 60.221, 
    lon: -152.745, 
    mag: 2.0, 
    depth: 103.8,
    place: "62 km WNW of Ninilchik, Alaska",
    color: "deep" // derived from depth
  },
  // ... more points
]

CODE IMPLEMENTATION:
```javascript
// Prepare scatter plot data with all dimensions
const scatterData = earthquakeData.map(d => ({
  latitude: d.latitude,
  longitude: d.longitude,
  magnitude: d.mag,
  depth: d.depth,
  place: d.place,
  // Color category based on depth
  depthCategory: d.depth < 25 ? 'shallow' : 
                 d.depth < 75 ? 'intermediate' : 'deep'
}));

// Color scale
const depthColorScale = d3.scaleLinear()
  .domain([0, d3.max(earthquakeData, d => d.depth)])
  .range(['#ff4444', '#4444ff']); // red to blue

// Size scale
const sizeScale = d3.scaleSqrt()
  .domain([0, d3.max(earthquakeData, d => d.mag)])
  .range([2, 20]); // min and max circle radius
```


========================================
5. BONUS: TIME-BASED BAR CHART CONNECTION
========================================

CHART TITLE: "When Do Earthquakes Strike? Hourly Activity"

DATA MAPPING:
- X-axis: Hour of day (0-23)
- Y-axis: Number of earthquakes
- Purpose: Shows temporal patterns in earthquake occurrence

WHY IT'S IMPACTFUL:
- Tests common myth: "Do earthquakes happen more at night?"
- Shows earthquakes occur randomly throughout the day
- Interesting for pattern-seekers
- Educational: Earthquakes aren't influenced by time of day

CODE IMPLEMENTATION:
```javascript
// Extract hour from timestamp
const hourlyData = Array.from(
  d3.rollup(
    earthquakeData,
    v => v.length,
    d => new Date(d.time).getHours()
  ),
  ([hour, count]) => ({ hour, count })
).sort((a, b) => a.hour - b.hour);
```
